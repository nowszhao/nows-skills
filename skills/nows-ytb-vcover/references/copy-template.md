# 发布文案模板（copy-template）

为 YouTube 视频生成中文社媒发布文案的格式规范与示例。适用于公众号、小红书、知乎、B 站等平台的二次分发。

## 产出文件结构

按视频 ID 建文件夹，每个视频产出两份文件：

```
<视频ID>/
├── 文案.md      # 发布文案（含可复制块）
└── 封面.html    # 1280×960（4:3）封面页面
```

批量（播放列表）场景：每集一个 `<视频ID>/` 子目录，可选在根目录放 `系列总览.md`。

## 文案.md 文件结构（五要素 + 可复制块）

```markdown
# <视频标题>

<!-- 长标题（可复制块） -->
### 📋 长标题
```text
<30-60 字中文标题，信息量 + 钩子>
```

<!-- 缩略图小标题（可复制块） -->
### 🖼 缩略图小标题
```text
<6-12 字短标题>
```

<!-- 封面标题（多套方案，供用户选一） -->
### 🎬 封面标题（主标题 + 副标题，选一套使用）
**方案一（封面.html 默认采用）**
```text
主标题：<观众关心的问题句式，悬念钩子>
副标题：<一句话内容定位>
```

**方案二**
```text
主标题：<另一角度的问题/断言>
副标题：<另一句定位>
```

**方案三（可选）**
```text
主标题：<第三角度>
副标题：<第三句定位>
```

<!-- 简介（可复制块，含地址/时间/内容/标签） -->
### 📄 简介
```text
原视频地址：https://www.youtube.com/watch?v=<id>
发布时间：YYYY-MM-DD ｜ 时长：h:mm:ss ｜ 播放量：<x.x万+>
频道：<channel>

【内容提炼】
- <要点 1：结合 description 与 chapters 改写的中文干货>
- <要点 2>
- ...

核心洞察：<一句话收尾>

【标签】
#标签1 #标签2 #中英混排 #TagStyle
```
```

**可复制块规则（必须遵守）：**
- 长标题、缩略图小标题、封面标题、简介四个区块**各自用 ` ```text ` fenced code block 包裹**，内容为纯文本；
- 块内**不得出现 markdown 符号**（`**`、`-` 列表、`>` 等），保证复制后直接粘贴到社媒编辑器无残留；
- 标签用空格分隔的中英混排（`#AIAgent #后训练`），不要用顿号或逗号；
- **封面标题必须给 2-3 套方案**（每套 = 主标题 + 副标题），标注"方案一/方案二/方案三"，封面.html 默认采用方案一；若用户选定其他方案，按所选方案重新生成封面。

## 规则

### 长标题
- 信息量 + 钩子：包含主题/嘉宾/频道 + 一个吸引点（反差、数字、争议、稀缺性）
- 中文为主，可夹少量英文专名（Claude Code、RAG 等）
- 30-60 字为宜；系列视频需带集号或主题定位

### 缩略图小标题
- 6-12 字，大字、有冲击力
- 用问句（"还需要吗？"）、对比（"从 X 到 Y"）、断言（"彻底讲透"）制造点击欲

### 简介
- **原视频地址**：必须 `https://www.youtube.com/watch?v=<id>` 纯净格式（去掉 `&list`/`&t`）
- **发布时间**：upload_date 是 YYYYMMDD，必须转 YYYY-MM-DD
- **时长**：秒转 h:mm:ss（<1h 用 mm:ss）
- **播放量**：≥1万 → "x.x万+"；≥1000 → "x.xK+"；否则用原始数字
- **内容提炼**：3-6 条要点 + "核心洞察"一句；要结合 chapters（时间戳标题是现成干货点）与 tags，中文改写，禁止直译英文 description
- **标签**：中英混排，主题词（2-4 个）+ 专名/人名/频道（2-3 个）+ 平台通用词；`#AIAgent` 风格无空格

## 封面标题设计指南

封面 HTML 的标题文案决定点击率，遵循以下原则：

### 主标题（h1）——用"观众关心的问题"句式
- 从视频中提炼**目标观众最想知道答案的问题**，直接抛出制造悬念；
- 句式模板：
  - "什么时候该 <做某事>？"（如"什么时候该从提示词走向自训模型？"）
  - "为什么 <反常识结论>？"（如"为什么便宜 80% 还是没人用？"）
  - "<难题>，到底怎么解？"
  - "从 X 到 Y，<关键变化> 在哪？"
- 2 行以内、普通标题 90-110px 大字；超长标题可降至 64px，但必须保持清晰可读；可用 `<span class="hl">` 高亮一个关键词（橙红渐变）；
- **禁止**：直接翻译视频英文原标题作为主标题。

### 副标题（sub）——一句话内容定位
- 交代视频到底讲什么，降低点进来后的跳出；
- 用"主题路径"或"覆盖范围"句式（如"Prompt → RAG → SFT → RL 的完整进阶路径"）。

### kicker（h1 上方小字）
- 最强卖点或场景引导（如"后训练 = 守住品味"、"官方拆解"），紫色小字。

### 其余元素
- **badge**（左上）：`<频道/嘉宾> × <来源>`；
- **feature-tag（差异化优势标签，必须强化）**：主标题上方的绿色发光大标签「真人感中文配音」（34px 大字 + 麦克风图标，置于 kicker 之前）——这是区别于其他视频的差异化优势，每个封面必须保留并保持醒目，不得删除、缩小或改动文案；
- **footer**：来源说明 + 时长（右上角 `live-tag` 可用"首发/实录/对谈"等场景词替换）。

## 封面纵向布局

- 采用 4:3 画布的紧凑三段式结构：`topbar → main → footer`，整体居中；
- 禁止用 `space-between` 或 `main: flex: 1` 把内容撑开；
- 控制外层间距约 36px，特色标签与 kicker 约 18px，kicker 与主标题约 12px，主标题与副标题约 20px；
- 目标是截图时内容聚拢、信息密度高，避免顶部标签与底部信息之间出现大块空白。

## 高质量示例

### 示例 1（概念教学类）
- 长标题：**19 分钟看懂 AI Agent 四大核心概念：Agent Harness、Loop Engineering、LLM Ops、Eval 一次讲清 | Sean's AI Stories**
- 小标题：**AI Agent 四大概念，19 分钟讲透**
- 标签：#AIAgent #AgentHarness #LoopEngineering #LLMOps #Eval #AI工程

### 示例 2（官方/大厂分享类）
- 长标题：**Anthropic 官方拆解：从原语到生产，Anthropic 是怎么构建 Agent 的？Skills、Sub-Agents、Evals、安全 Hooks 全覆盖 | Databricks Meetup**
- 小标题：**Anthropic 如何把 Agent 送上生产**
- 标签：#Anthropic #ClaudeCode #AgentSkills #SubAgents #MCP #Evals #AI安全

### 示例 3（访谈/战略类，问题式封面主标题示范）
- 长标题：**Jeff Dean 离开 Google 后首次公开演讲：AI 的下一个前沿不是回答问题，而是"做出发现"| Discovery Loop**
- 小标题：**AI 的下一站：从答问到发现**
- 封面主标题（问题式）：**AI 下一站，只答问题够吗？** ｜ 副标题：从 Google 到 Discovery Loop，Jeff Dean 首讲
- 标签：#JeffDean #DiscoveryLoop #AI #Gemini #AIforScience #科学发现

## 批量模式

播放列表场景：每集一个 `<视频ID>/` 子目录（`文案.md` + `封面.html`），根目录可选 `系列总览.md`：

```markdown
> 系列名称：**<系列名>**
> 频道：**<频道名>**
> 定位：<一句话定位>
> 播放列表：<playlist URL>
> 共 <N> 集，每集文件位于 <视频ID>/ 目录下
```
