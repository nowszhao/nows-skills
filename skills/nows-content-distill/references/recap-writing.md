# Recap Writing · 最简复述

最简复述是认知刻印的**最终自检**：如果你不能在 500 字内复述清楚，就证明你没真的理解。

## 一、硬约束（违反任一即不合格）

| 约束 | 说明 |
|---|---|
| **字数 ≤500 字** | 中文字符数。必须做 word count 校验。超过就裁，不允许 501 |
| **必须是连贯散文** | 整段 / 多段 `<p>`，**禁止任何项目符号、列表、小标题** |
| **禁止抄原文整句** | 必须用自己的话重述。引用最多 1 处且加引号 |
| **必须含四要素** | 问题 / 主张 / 证据 / 结论 缺一不可 |
| **饭桌口吻** | 模拟"饭桌上跟朋友讲这一篇"的语气，不是论文摘要 |

## 二、四要素结构

虽然形式是连贯散文，但内容上必须暗含四段（不写小标题，但段落自然分布）：

1. **问题**（≈80 字）：这一篇在回应什么？背景是什么？为什么这事值得讨论？
2. **主张**（≈80 字）：作者的核心判断是什么？
3. **证据**（≈250 字）：作者凭什么这么说？最有说服力的论据 / 案例 / 机制是什么？
4. **结论**（≈90 字）：所以呢？读者应该怎么看 / 怎么用？

字数分配是参考，不是死规定，但 250 字的"证据"段不允许被压成 50 字——证据是骨头，骨头薄了就立不住。

## 三、"饭桌口吻" 的判定

合格的语气示例：

> 这篇主要在回答一个问题：为什么大厂今年都在砍中台。文章的判断是，中台不是被技术淘汰的，是被组织淘汰的——当业务部门发现中台响应不了自己的节奏时，宁可重复造轮子也不愿等。作者举了三个例子……

不合格的语气示例：

> 本文围绕中台架构的兴衰展开论述，作者从组织维度切入，提出了若干洞见……（论文腔）

> 中台原来是这么回事啊！😱 作者一针见血指出……（公众号腔）

判定标准：**读起来像跟人讲，不像念给人听。**

## 四、自检反问（写完必做）

写完 500 字后，合上原文，自问以下 4 题。任一答不出 → 复述不合格，回炉：

1. 这一篇在回应什么问题？
2. 作者的核心主张是什么？
3. 哪个论据最有说服力？
4. 我看完，下一步应该做什么 / 怎么想？

## 五、反模式

- ❌ 写成"先说了 A，再说了 B，最后说了 C"的流水账
- ❌ 用项目符号 / 编号列表
- ❌ 抄原文整句不加引号
- ❌ 主张和结论分不开（两句话其实在说同一件事）
- ❌ 字数压不到 500（必须裁，不允许"刚好 510 字也算"）
- ❌ 论文腔 / 公众号腔（要饭桌腔）

## 六、字数核对方法

写完后用以下任一方式核对：
- Python：`len(re.findall(r'[\u4e00-\u9fa5]', text))` 统计中文字符
- 命令行：`echo "<文本>" | wc -m`（粗估，含标点和英文，可作为上限参考）
- 直接数（短文）：500 字大约是 5–7 个微信公众号标准段落

无论用哪种方式，**必须留下字数核对的证据**（写在 frontmatter 的 `word_count` 或 MD 末尾）。
