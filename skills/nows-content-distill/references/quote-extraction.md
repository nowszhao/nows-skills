# Quote Extraction · 值得记住的话

心理表征要落地，必须有"可背诵的颗粒"。**一句金句胜过一段总结。**

## 一、数量

**3–7 句**。少了不够锚，多了记不住。

## 二、强制结构

```markdown
> {{原文金句，逐字摘录}}

为什么值得记：……（≤50 字）
```

## 三、"逐字摘录" 是核心约束

### 必须

- 一字不改地从原文 / 转录里摘
- 中文标点保留原状（包括"——"、"：" 这些）
- 英文原文保留英文（不做翻译）
- **视频金句必须配时间戳**（无时间戳即不合格）：

```markdown
> Coding is no longer the bottleneck.

为什么值得记：……
（视频 [00:05]）
```

### 必须做的命中校验（每条金句都要做）

**收录前**：把金句拿到原文 / 字幕里 **ctrl-F 命中**：
- 文章：在原文里搜，必须能搜到
- 视频：在 .vtt / 转录文本里搜，必须能搜到，且**记录时间戳**（取首次出现的那一段）
- 命中不了（或只能命中部分单词，整句对不上）→ **禁止收录**，这条多半是模型自己生成的伪金句

**自检反问**：
1. 这句话能不能在原文里逐字搜到？
2. 时间戳对得上原文吗？
3. 是不是把两段不相邻的话拼成了一句？

任一答 ❌ → 删掉换一句。

### 禁止

- ❌ 改写 / 意译 / "总结一下作者的话"——那不是金句，是你的话
- ❌ **拼接两句不相邻的话伪装成一句**（这是高发陷阱）：如把第 5 分钟和第 47 分钟的两句拼起来看着更像金句
- ❌ **模型自行生成"听起来像该作者说的话"**（如套用类似 podcast 的常见格言塞进来）
- ❌ 把作者引用的别人的话当作者金句（必须区分；如果引的是别人，要标注 "作者引用 X：……"）
- ❌ 视频金句不配时间戳

## 四、金句的两种类型（必须区分）

| 类型 | 特征 | 复用价值 |
|---|---|---|
| **观点型** | 作者下的判断 / 提出的洞察 | 高（可在新场景套用） |
| **事实型** | 作者引用的数据 / 案例 / 历史 | 中（必须配出处） |

事实型金句必须在 "为什么值得记" 里附上**出处**或**核对路径**：

```markdown
> GPT-4 训练成本约 1 亿美元。

为什么值得记：印证大模型护城河来自资本而非算法。
（数据出处：作者引用 SemiAnalysis 2023 年估算，未亲验）
```

## 五、"为什么值得记" 的写作

≤50 字，必须命中以下至少一种：

- 戳到一个**普遍误区**（"我以前一直以为……")
- 揭示一个**核心机制**（"这是 X 之所以 work 的本质"）
- 给出一个**反直觉点**（"反过来才对"）
- 提供一个**可迁移的判断模板**（"以后看到 X，就这么判断"）

如果写不出上面任何一种 → 这句话不值得记，删掉换一句。

## 六、反模式

- ❌ 摘的是"过渡句"或"承接句"（没有独立信息量）
- ❌ 摘了一段而不是一句（金句必须是单句或最多两句紧密连贯）
- ❌ "为什么值得记" 写成"这句话很有道理 / 很精彩"（赞美不是分析）
- ❌ 7 句以上（记不住）
- ❌ 全部都是观点型 / 全部都是事实型（说明你只看到了一面）
