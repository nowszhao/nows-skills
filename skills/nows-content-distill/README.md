# nows-content-distill

把一篇文章 / 一个 YouTube 视频，**压缩成"刻进脑子的心理表征"**。

不是摘要工具，是**认知刻印器**——给自己用，不是给别人看。

## 它干什么

输入：
- 文章正文（粘贴）
- 文章链接（自动抓正文）
- YouTube 视频链接（自动抓字幕）

输出固定 5 项处理：
1. **核心概念** — 3–7 个关键术语，一句话讲清楚
2. **行文逻辑** — 反向工程出作者思路，按金字塔结构呈现（顶层主张 / 论点 / 论据）
3. **差异化亮点** — "多数人会说什么 vs 这一篇说什么"，强制先调研后落笔
4. **值得记住的话** — 3–7 句逐字摘录的金句 + 为什么值得记
5. **最简复述** — ≤500 字的连贯散文，模拟"饭桌上跟朋友讲这一篇"

产物：
- `<slug>-distill.md`（中间产物，可手工修订）
- `<slug>-distill.html`（单文件、零依赖、笔记风、深色模式自动切换、打印友好）

## 你可以怎么说

- "帮我把这篇文章 distill 一下：<URL>"
- "帮我刻印一下这个视频：<YouTube URL>"
- "压一下这篇文章，我想留下心理表征"
- "做一份阅读笔记卡，我看完想记住"
- "把这内容内化一下"

## 安装

```bash
mkdir -p ~/.workbuddy/skills
cp -R skills/nows-content-distill ~/.workbuddy/skills/
```

如果用 `~/.claude/skills/`，把目标目录替换一下就行。

## 可选依赖

抓 YouTube 字幕和文章正文用得上：

```bash
pip install youtube-transcript-api yt-dlp trafilatura readability-lxml
```

都不装也能跑：
- 文章 URL 会走 `r.jina.ai` 兜底（无需 API key）
- YouTube 抓不到字幕时会**直接停下来**让你手工提供转录（不允许"模型先验硬上"）

## 设计取舍

- **抓不到 = 停下来**。输入污染就是认知污染，禁止用模型已有知识硬填
- **差异化必须先调研**。先用 web search 建立"默认认知基线"，再判断这一篇凭什么不一样
- **金句必须逐字摘录**。改写过的句子失去节奏密度，不再是"原话"
- **复述必须散文**。用项目符号写复述等于没复述，骨架要立在自己脑子里
- **HTML 风格固定**。颜色、字体、5 个 section 的视觉处理都写死，模型不能自由发挥——这样产物可重复、可对比、可归档

详细设计见 `SKILL.md` 与 `references/` 目录。
