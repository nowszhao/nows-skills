# 可行性分析：商业模式验证（第2章）

## 核心问题

商业模式能从导入期过渡到成长期吗？判断"行业会不会死"——如果会死，连下注的必要都没有。导入期最重要的研究维度。

## 什么是商业模式

商业模式 = 生产力要素 × 生产关系要素的排列组合
- 生产力三要素：劳动者、劳动资料、劳动对象
- 生产关系三要素：生产资料所有制、生产中地位与相互关系、产品分配方式

实操工具：**商业模式画布**（9 要素：客户细分、价值主张、渠道、客户关系、收入来源、核心资源、关键业务、重要合作、成本结构）。习惯：先找几份行业研报，对照画布按图索骥填满。

**注意**：商业模式没有标准答案。同一行业可有多个可行模式（微信 vs Soul；小米 vs 苹果；阿里 vs 京东）；同一公司也可有多种模式（宝洁多品牌、财新卖会员+广告）。

## 验证方式（资本视角）

- **调研法**（快消品常用）：问卷调查、追踪观察（24h 观察用户）、焦点访谈
- **试错法**（VC 常用）：让创业者用试错验证，看重"调头能力"（pivot）；"赛道投资"（投赛道不投赛手，红杉式：多团队同时试错，最后推动合并）
- 对导入期行业，个人投资者做不了大规模验证，只能做**事前评估**：目标是确保胜率不是 0%，投资是胜率和赔率的权衡

## 两步评估法

### 第一步：销售可行性评估（卖不卖得出去）

验证需求是否真实存在。两个对标法：

**时间对标法**（往前看历史）：
- 底层假设：需求是永恒的，产品和服务一直在变
- 成功的商业模式往往不是创造新需求，而是用新方式满足已有需求
- 例：吃饭需求→干粮→方便面→外卖→预制菜；出行需求→走路→轿子→马车→汽车
- 反例：共享篮球（创造的是伪需求——篮球租赁历史上没有）

**空间对标法**（对标成熟市场）：
- 底层假设：人类底层需求相通，成熟市场经验可参考
- "时光机理论"（孙正义）：新事物先在美国→日本→新兴市场；C2C 模式
- 反例：对标对象本身是新生事物时风险大（Clubhouse 式跟风）

### 第二步：利润可行性评估（赚不赚得到钱）

**定性分析**：
- 收入端：需求排序，两个好特征（至少取其一）——
  - **频次高**（用得多，销量大）
  - **弹性小**（刚需、依赖强、可定高价）→ 弹性 = 需求量对价格变动的敏感度
  - 矩阵示例：吃饭（频次高弹性小，餐饮毛利 40-60%）；婚庆（频次低弹性小，靠高价但获客贵）；景点骑马（频次低弹性大，差生意）
- 成本端：看**标准化程度**——标准化越高成本越低、越可复制（海底捞选火锅而非炒菜；SaaS 标准化高难卖高价，咨询定制化高卖高价）
- 注意：需求优先级排序可用马斯洛金字塔辅助（东南亚卖太阳能照明的案例：当地刚需是制冰不是照明）

**定量分析——UE 模型（单位经济模型）**：
- 最小运作单位：能体现收入成本关系的最小单元（餐饮=单店、网约车=单车、美妆=单品、外卖=单订单）
- 单店模型（供给侧）：估算代表性门店一年利润 → 判断能否复制扩张
- 单客模型（需求侧）：计算每个客户贡献利润与获客成本 → 优化营销投入
- 关键指标（如餐饮翻台率）：找对关键指标 = 行业经验 + 专家意见 + 龙头数据参考
- **终局视角**：当前亏损不致命，看规模扩张能否改善（外卖早期每单亏损→订单密度提升→扭亏）；建 3 个模型：当前/盈亏平衡/终局
- UE 能赚钱 → 商业模式基本可行（有规模效应行业）

**无法收费的模式**（微信式）：免费给用户，靠广告主/商家付钱，衡量指标是 ARPU（每用户平均收入）。导入期难量化 → 牛市易被高估。

## 创新层级（判断时机）

创新有先后：基础层（基础设施）→ 中间层（硬件/操作系统）→ 应用层（应用/生态）。应用层创新依赖底层成熟（2015 年前新能源车因电池材料不成熟而缺乏竞争力）。若前置创新未成熟，商业模式可能"生不逢时"长期停滞导入期。
