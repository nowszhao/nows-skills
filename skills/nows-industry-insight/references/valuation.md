# 估值分析（第6章）

## 核心认知

- 股票收益 = 股利所得 + 资本利得；资本利得 = 盈利增长 + 估值变化
- 长期（百年尺度）估值变化趋于均值回归影响小，但个人/机构的投资周期内估值影响巨大（1981-2000 美股年化 17%：分红 4% + 盈利 6% + 估值 7%；2009-2022 沪深300 年化 8%：分红 2% + 盈利 10% + 估值 -4%）
- 业绩增速越快 → 估值倍数越高（PE = 回本周期）

## 估值由投资者和资产共同决定

### 投资者角度（需求端）

1. **能力（钱多不多）**：受宏观货币政策影响。央行宽松 → 无风险利率低 → 估值容忍度高 → 估值提升（全 A 市盈率与 M1 同比同向波动；2020 美联储降息零利率+无限 QE → 美股两年大牛市）；收紧则相反。关注**边际变化**（市场围绕预期差交易：预期加息时美股已开始跌，可用 FedWatch 工具观察加息概率预期）
2. **意愿（风险偏好）**：乐观/悲观情绪；交易拥挤度——某板块成交额占比/换手率过高 = 看涨者几乎全部入场 = 风险信号（广发经验值：成交额前 5% 个股占全 A 比重超 45% 为高风险；兴证 7 指标等权合成拥挤度，超均值+1.5σ 危险、破均值-1.5σ 且景气好是买点）

### 资产角度（供给端）

- **赔率**（盈利空间/亏损空间）与**概率**（胜率）。赔率越高、概率越高，估值越高；高赔率高概率难兼得
- 与基本面四维对应：可行性→存活概率；规模性→赔率（天花板）；防守性→不被替代的概率；盈利性→利润改善空间的赔率
- 案例：腾讯（大基数+反垄断 → 成长空间触顶 → 赔率下降 → PE 回落）；茅台（增速 10% 出头但品牌力强 → 概率高 → 稳定 30-40 倍 PE）

## 相对估值（行业层面分析工具）

**行业相对估值 = 行业市盈率 ÷ 全部 A 股市盈率**——排除宏观干扰的"尺子随大盘调整"。>1 高于大盘，<1 低于大盘。

## 各阶段估值特征（重点）

| 阶段 | 估值特征 |
|------|---------|
| 导入期 | 盈利低/亏损，PE 无意义；看远期空间，二级市场"主题投资/市梦率"（三位数 PE）；上得快下得快，适合"节奏大师" |
| 成长前期 | 商业模式跑通、业绩超预期，估值冲高（100% 增速敢给 100 倍 PE；科创板首批平均超 200 倍）；警惕交易拥挤 |
| 成长后期 | 增速回落、难超预期，高估值难以为继；**相对估值顶部常出现在成长后期** |
| 成熟期 | 渗透率超 50% 后增量少，估值收缩（城镇化率超 50% 后地产/银行/工程机械集体杀估值）；龙头竞争格局改善可"龙头进阶"估值提升 |
| 衰退期 | 三种可能：①第二增长曲线→视为新行业（多元化公司用**分部估值法**）；②稳定市场周期化→参考成熟市场 PE；③被替代→估值走低（除非供给收缩快于需求→"回光返照"拔估值：煤炭） |

## 实战案例参考

- **空调行业**：导入期（90 年代初渗透率<5%）估值大起大落（相对估值 0.8→0.4）；成长期（1997-2005 渗透率 16→81 台/百户）估值随渗透率上行（0.4→0.8），2000 年价格战+库存危机后估值中枢回落；成熟期（价格战洗牌、格美海三足鼎立、CR3 37%→55%）竞争格局改善估值回到 0.8
- **智能手机零部件**：导入期+成长期 PE 80-120 倍（歌尔 2010 年 90 倍，"戴维斯双击"）；成长后期 40-80 倍；成熟期 20-40 倍

## 分析纪律

- 估值分析目的是判断"当前价格隐含了怎样的预期"，并与基本面判断交叉验证
- 区分估值倍数高低的原因：是行业阶段使然（合理）还是市场情绪使然（风险）
