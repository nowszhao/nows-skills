# 产业生命周期主框架（第1章）

## 核心：用渗透率划分阶段

传统产业生命周期理论（S形曲线、按时间或斜率分段）缺乏实操性。**用渗透率分段**：

- 渗透率 = 存量用户 ÷ 潜在客户群
- **15%~20%**：导入期 → 成长期（行业进入快速提升阶段）
- **35%~40%**：成长期 → 成熟期（行业增长放缓）

### 渗透率口径选择（关键技巧）

- 长替换周期行业（汽车、家电等）：用**新车渗透率/年销量渗透率**，而非存量保有量渗透率（如新能源汽车：存量渗透率仅 7% 但新车渗透率 40%，应按新车口径判阶段）
- 可类比：TAM 与 SAM 之比 ≈ 渗透率（销售额口径）

### 创新扩散理论（理解底层逻辑）

用户按接受新事物的速度分五类：创新者 → 早期采用者（KOL/KOC）→ 早期大众 → 后期大众 → 落后者。行业所处阶段对应主流用户类型：
- 导入期：只有创新者使用
- 成长期：早期采用者+早期大众入场
- 成熟期：后期大众入场，新客增长放缓，靠复购
- 衰退期：无增量用户

## 各阶段特征与研究重点

| 阶段 | 典型特征 | 首要研究重点 | 次要 |
|------|---------|------------|------|
| 导入期 | 产品未定型、概念炒作、骗子蹭概念、公司蹭热点 | 商业模式**可行性**（需求真实吗？能赚钱吗？） | TAM、防守性 |
| 成长期 | 供不应求、毛利不错、竞争者涌入、价格战 | 市场**规模性**（TAM 天花板 + 未来3-5年空间） | 竞争格局初现 |
| 成熟期 | 产品标准化、毛利下滑、估值下台阶 | 护城河（**防守性**）+ 竞争格局（**盈利性**） | 第二增长曲线 |
| 衰退期 | 替代品出现、产能过剩、价格毛利双低 | 替代品威胁 | 供给收缩下的机会 |

**重要**：各阶段都有重点，但不代表其他维度不用看，只是**权重不同**。

## 成熟期的三种可能（关键判断）

1. **被替代** → 进入衰退期
2. **第二增长曲线** → 开发新品/新技术/新市场，视为重新进入导入期分析
3. **稳定市场周期化** → 护城河守住了，需求随宏观起落、供给随库存/产能/金融周期波动，成为周期性行业（银行业、白酒业）

## 各阶段估值特征概览

| 阶段 | 估值逻辑 |
|------|---------|
| 导入期 | 一级市场 VC 估值；二级市场"主题投资/市梦率"，看重远期空间 |
| 成长前期 | 业绩超预期、估值冲高，警惕交易拥挤 |
| 成长后期 | 增速回落、估值难以为继，相对估值顶部常在此 |
| 成熟期 | 估值收缩；竞争格局改善的龙头可"龙头进阶" |
| 衰退期 | 第二增长曲线（分部估值法）/ 稳定市场周期化（参考成熟市场）/ 被替代（估值走低，除非供给收缩快于需求收缩的"回光返照"） |

## 动态追踪

行业持续变化：内部因素 + 外部因素（PEST）都会推动或阻碍演化。曾经的驱动力可能变成限制因素（如税收优惠到期）。需持续跟踪景气度验证判断。

## 行业分类标准（Step 0 用）

- 《国民经济行业分类》——国家标准（国家统计局数据口径），三大产业划分
- 《上市公司行业分类指引》——证监会
- 《申万行业分类标准》——申万宏源研究，三级颗粒度，罗马数字标层级（游戏Ⅱ=二级）
- GICS——标普+MSCI 制定，投资美股常用
- 注意：标准会随社会发展修订（申万 2021 年新增医美等）
