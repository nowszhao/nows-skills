# 盈利性分析：竞争格局（第5章）

## 核心问题

稳定市场周期化阶段，蛋糕不再变大，谁最赚钱？竞争格局决定企业盈利。从供给侧看：横向格局（同行怎么分）+ 纵向格局（上下游怎么分）。

## 横向格局：行业集中度

### Know-what：关键指标

- **市占率**：单公司销售额 ÷ 行业销售额。体现对上下游议价能力
- **行业集中度 CRn**：市占率前 n 名之和（常见 CR3/CR4/CR5/CR8）
- 市场结构四分类（按 CR8）：
  - 分散竞争型 0-20% / 低集中竞争型 20-40%（合称"竞争型"）
  - 低集中寡占型 40-70% / 极高寡占型 70-100%（合称"寡占型"）
- 集中度与盈利能力正相关（有色金属→家电，营业利润率随 CR8 变化）
- **数据局限**：万得/Choice 的 CRn 只统计上市公司，未上市公司多的行业会失真（餐饮住宿 CR8 高达 90.85% 实为数据假象）。正确做法：上市公司销售额合计 ÷ 测算的全行业市场规模

### Know-why：变化主因

- **与宏观经济反向**：经济下行期集中度提升（龙头抗风险强、中小企业出清）；上行期集中度下降
- **产业政策**：刺激需求→集中度下降（扶弱）；限制供给→集中度上升（供给侧改革、双碳限产能）
- **生命周期**：集中度先降后升——导入期高（少数先行者）→成长期降（大量涌入）→成熟期升（淘汰兼并）→衰退期只剩少数
- **集中度天花板因行业而异**：空调/智能手机 CR3 达 70%，白酒 CR3 仅 10-20%。判断天花板：对标成熟市场（欧美日韩经验）——进入壁垒由行业特性决定，跨国比较合理

### 稳定市场周期化后的关键：产能周期

**产能**：现有条件下最大产量；**产能利用率** = 实际产量 ÷ 最大产能。

产能周期四阶段：供不应求 → 产能激增 → 产能出清 → 格局改善。
供需缺口两成因：①企业家反应速度滞后（建厂周期长）；②企业家心态（预期差，高估自己能吃下的份额——共享单车过度投放）。

**判断产能周期阶段**：

1. **定性**：产能扩张三阶段——龙头被动扩产 → 龙头主动扩产 → 外来者无序扩产（外来者涌入 = 离波峰不远；龙头减产 = 近底部）
2. **定量**：供需平衡表（跟踪新增产能释放节奏：上市公司公告/调研/投资者互动平台；预测需求：有指引行业好预判如白酒/CXO 在手订单，成长周期行业只能"模糊的正确"+ 跟踪终局兑现节奏）
3. **资本性支出（CAPEX）**：现金流量表科目相减，或净经营长期资产增加+折旧摊销之和；**CAPEX÷折旧摊销 < 1.5 甚至 < 1 = 供给收缩、格局改善的底部信号**（行业拐点前兆）
4. **库存周期**：主动补库→被动补库→主动去库→被动去库；库存历史高位=供过于求危险信号，历史低位=供不应求或磨底（汽车经销商库存系数 ≥2.5 = 库存过高）
5. **辅助指标**：行业底部 = 龙头减产+玩家退出+卖方分析师不再推荐；顶部 = 龙头扩产+外来者涌入+卖方跳空式评级上调

**两个例外**：①结合生命周期看（衰退期缩产能≠没机会——煤炭：供给收缩快于需求收缩→价格上涨"回光返照"）；②龙头不按常理出牌（逆势扩张抢份额：靠融资支持；主动打价格战淘汰中小玩家：2000 年空调、2022 年新能源车）。

## 纵向格局：产业链利润分配

**产业链**：供应商的供应商→……→客户的客户。产业链分析是行业研究的基础（商业模式是产业链在单公司层面的映射）。

### Know-why：分配机制

利润分配取决于**议价意愿 × 议价能力**：

- **议价意愿**：①商品/服务在下游的价值占比（螺丝占整车成本低→车企不在意涨价；占比高→必谈）；②行业周期阶段（成长期大家有肉吃、愿意让利；成熟期蛋糕固定→强势方拿高毛利，消费成熟赛道品牌方毛利最高）
- **议价能力**：对手方有没有得选——看各环节的**行业集中度**和**供需情况**（供不应求、技术含量高的环节拿走利润大头：2021 年光伏硅料毛利飙到 80% 而电池片接近 0%）

### Know-how：判断指标

1. **毛利率**：谁毛利率高谁强势（美妆：品牌商 60-80% vs 经销商低）
2. **占用上下游资金能力**：应付账款+预收账款+合同负债（占用别人）vs 应收账款+预付账款+合同资产（被占用）——多在单公司层面分析

## 关键结论

- 成熟期投资逻辑：从"赛道投资"转向"精选个股"——找产业链最赚钱的环节、最强的龙头
- 某个环节赚得多 ≠ 该环节企业赚得多（要看横向集中度：化妆品终端渠道分走 50% 但高度分散）
- 更应关注**分配比例的变化趋势**而非绝对值：某环节占比上升 = 利润率改善
