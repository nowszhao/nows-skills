# 输出模板（最终推荐阶段）

诊断完成后，严格按以下模板输出。可以直接复制粘贴当骨架，把方括号占位符替换成实际内容。

```markdown
═══════════════════════════════════════
📍 你当前的认知 i
═══════════════════════════════════════
**已掌握**：
- [核心逻辑 1，用作者的原意复述]
- [核心逻辑 2]

**尚未稳固**：
- [诊断中暴露的薄弱点 1]
- [诊断中暴露的薄弱点 2，可选]

═══════════════════════════════════════
🎯 i+1 优先精读（小节级）
═══════════════════════════════════════
**1.《[书名]》第 X 章 第 Y 节《[小节标题]》**
- 为什么是你的 i+1：[1 句话，关联到诊断结果]
- 读这节带着的问题：[1 个引导性问题]
- 预计阅读：[X 分钟 / X 页]

**2.《[书名]》第 X 章 第 Y 节《[小节标题]》**
- ...

[一般 2–4 个小节，最多 5 个]

═══════════════════════════════════════
📖 可略读（扫一眼即可）
═══════════════════════════════════════
- 第 X 章《[标题]》：[原因，例如"你已掌握等价逻辑"或"全是补充案例"]
- 第 X 章《[标题]》：[原因]

═══════════════════════════════════════
⏸ 暂不学习（i+2 及以上，缺前置）
═══════════════════════════════════════
- 第 X 章《[标题]》：缺前置 [具体概念]，等读完 i+1 再来
- 第 X 章《[标题]》：[原因]

═══════════════════════════════════════
💡 学习理由
═══════════════════════════════════════
[3–5 句，回答这 3 个问题：
1. 为什么这条路径比"从头读"更高效？
2. 为什么不直接挑感兴趣的章节读？
3. 读完 i+1 你将获得什么具体的认知升级？]

═══════════════════════════════════════
🔁 下一轮诊断
═══════════════════════════════════════
读完上述内容后，回来告诉我"读完了"。
我会基于你的新认知层出 2–3 道更深的逻辑题，
验证吸收程度，再给你下一个 i+1。
```

## 输出时的常见错误

❌ 写成"建议精读第 3 章" — 必须到小节级
❌ 推荐 6 个以上小节 — 违反 i+1 原则，一次最多 4–5 个
❌ "学习理由"里只夸书好，不解释为什么对**这个用户**是最优增量
❌ "暂不学习"里不说缺什么前置 — 用户不知道下一步该补什么
❌ 把"可略读"变成"也读一下吧"的妥协 — 要有明确判断
