# 正式输出模板（面向最终读者）

完整分析默认输出以下内容，依材料规模合理压缩；不强制表格承载长文本，确保手机上可读。用 Markdown 标题、缩进、短段与少量表格。引用真实的来源锚点，例如`§3.2`、`第 12 段`、`P.7`、`[00:14:32]`，**没有就写未定位**。

## 0. 来源与覆盖

> 材料：标题｜作者/讲者｜日期（若可得）｜媒介｜来源链接
>
> 阅读范围：`完整 / 片段 / 仅摘要 / 部分字幕`；覆盖的章节/时间段；涉及自动转写或画面缺失时说明。
>
> 核验方式：`仅原文分析 / 原文＋外部核验`；未核验哪些重要主张。

## 1. 30 秒建立全局认识

**核心问题 Q0：** ……？

**作者的总体答案：** ……（如属分析者归纳，明确说“归纳”；原文无答案时如实标注）

**论证主线：** 起点事实/痛点 → 核心机制/判断 → 关键证据/案例 → 行动或结论。

**最明显的证据缺口/争议：** ……

控制在约 120–220 字；短材料可更短。

## 2. 信息增量雷达（优先阅读）

依“读者可能会更新认知的程度 × 原文证据/外部可信度 × 与中心问题的相关性”排序；这是**定性**判断，不制造虚假打分。优先 3–7 项；如果没有值得确认的不同观点，直说没有。

每条：

**① [最值得注意的论点，用一行结论表达]**

- **不同在哪**：相对什么常见解释/做法（未核实则写“作者相对于其所描述的常见做法”）。
- **作者凭什么说**：依据＋原文锚点。
- **共识状态 / 证据强度**：从四维标签中选，避免误导。
- **适用与风险**：什么条件下可能成立，哪里还欠证据。
- **对应 FAQ**：`Q2.1`。

可把内容分组：`已具证据的新发现`、`作者特别的解释`、`值得核实的反常识主张`。不要把“常识被讲得好”强行标成业界独有。

## 3. 问题金字塔（完整目录）

```text
Q0  [核心问题]？→ [作者总体答案，尽量 1 句]
├─ Q1  [一级问题]？→ [一句话答案]
│  ├─ Q1.1 [子问题]？→ [一句话答案]
│  └─ Q1.2 [子问题]？→ [一句话答案]
├─ Q2  [一级问题]？→ [一句话答案]
│  ├─ Q2.1 ...
│  └─ Q2.2 ...
└─ Q3  ...
```

也可用无代码块的嵌套列表代替。层级取决于原文，不为达到固定数量增加问题。显式提问标`[明示]`，抽象归纳标`[隐含]`；标记可以在同类多时统一说明，不逐行赘述。

**完整性：** 原文主要论述区域 `章节/时间范围 → 对应 FAQ ID` 的覆盖索引。只列主要范围，不重复全部证据。

## 4. FAQ 证据卡（逐项展开）

### Qx.y  [精确的问句]

- **提问来源**：明示 / 隐含重建；**作者是否真正回答**：明确回答 / 仅暗示 / 未回答。
- **答案**：作者说……（若是分析者归纳则标明）。
- **论证**：前提 A → 机制/推断 B → 结论 C；断点或未经验证的推断写清楚。
- **原文依据**：`[页码/小节/时间戳]` + `数据 / 实验 / 案例 / 经验 / 类比 / 推理 / 无`；可以极简转述关键事实。
- **外部核验**：仅当实际检索时列可靠来源与支持/反对/未决结论；未查写`未执行`。
- **标注**：`主张类型 | 共识状态 | 差异性 | 原文证据强度`，并给一个简短的判断理由。
- **边界/反例**：原文限制、反驳或“原文未覆盖的条件”；勿把无证据当证据。

可将纯定义/背景的次要子问题压缩为一句话答案＋原文锚点；涉及重大结论或争议的 FAQ 必须使用全字段，不能遗漏证据和限定。

## 5. 关系图与逻辑链

至少说明实质性**跨节点**关系，例如：

```text
Q1.2 --[为其提供证据]--> Q1
Q2.1 --[前置条件]--> Q3.2
Q3.1 --[反驳]--> Q2.2
```

每个重要关系再附一处来源锚点或可解释的论证连接；不能仅因为主题相似就画箭头。若无可验证的跨节点关系，说“主要为并列话题”。

## 6. 仍值得追问

- **未回答**：原材料明确提出但没有回答的关键问题。
- **不确定**：需要哪些数据/反证才能确认某个核心判断。
- **下一步**：读者最值得核实或实践的 3 个具体问题；与作者原文问题分开。

## 写作控制

- 先看懂、再审查、最后扩展；先问题后回答，绝不“摘要+摘要+摘要”。
- 结论前置，给证据时尽可能复查定位。
- 不重复前言、不机械全篇逐字改写。
- 如果来源非常长，允许分页或按章节分批输出，首轮至少完整目录＋重点 FAQ；明确未展开项，用户要求全部时尽量完整给出。
- 字幕中的数字、时间、专名与否定词要格外核实。
