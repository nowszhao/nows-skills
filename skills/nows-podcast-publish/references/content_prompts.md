# 播客单集内容生成 Prompt 模板

## 1. 单集介绍 Prompt

用于生成「本期核心内容」「你将听到」「适合谁听」三个板块。

```
请根据以下视频字幕，生成一份播客单集介绍，结构如下：

## 本期核心内容
用3-5句话概括这期节目最精华的内容，说清楚讲了什么、有什么价值，让用户一眼决定要不要听。

## 你将听到
用6-10个要点列出节目中的关键话题、观点或故事，方便用户直接跳转感兴趣的部分。

## 适合谁听
用3-5个标签/短句描述最适合听这期节目的人群（如：想提升表达力的职场人、对AI感兴趣的小白等）。

要求：语言简洁有力，不废话，不夸大，总字数控制在400字以内。

---

字幕内容如下：
{SUBTITLE_TEXT}
```

## 2. 章节导航 Prompt

用于生成带时间戳的章节导航，格式为：

```
00:00  【章节名】简介... 🧡🧡🧡🧡🧡
```

```
请对以下视频字幕内容进行结构化总结，生成一份"章节导航摘要"，帮助用户快速了解全片讲什么，并判断哪些部分值得细看。

要求如下：
1、按主题划分章节：根据讨论的核心话题或逻辑转折点，将整段字幕自然切分为若干章节（数量不限，视内容而定），每个章节应有明确的主题标签（如"问题引入""核心观点""案例拆解""方案对比""总结展望"等）。
2、标注精准时间戳：为每个章节提供对应的起始时间（MM:SS或HH:MM:SS），时间点需对应字幕中该主题首次出现或重点展开的位置。
3、撰写章节简介：每个章节用 1~2 句话概括该部分的核心内容、关键论点或重要事实，让用户一目了然。
4、附加"观看建议"（可选但推荐）：在每个章节简介后，用简短标签提示该章节的价值类型，例如：
[必看] — 核心干货，建议完整观看，展示为：🧡🧡🧡🧡🧡
[选看] — 补充背景或案例，可根据兴趣跳过，展示为：🧡🧡🧡🤍🤍
[快进] — 过渡或重复内容，可快速浏览，展示为：🤍🤍🤍🤍🤍
注意[必看]需要加粗显示
5、输出格式（严格按此模板）：
00:00  【章节名】简介内容... 🧡🧡🧡🧡🧡
10:23  【章节名】简介内容... 🧡🧡🧡🤍🤍
30:00  【章节名】简介内容... 🧡🧡🧡🧡🧡
40:00  【章节名】简介内容... 🧡🧡🧡🧡🧡
01:00:22  【章节名】简介内容... 🧡🧡🧡🧡🧡
01:33:23  【章节名】简介内容... 🤍🤍🤍🤍🤍
...

字幕内容如下（请处理"###"内的文本）：
###
{SUBTITLE_TEXT}
###
```

## 3. 标题格式

按音频文件名地道翻译为中文，格式：

```
专访 | {中文标题}
峰会 | {中文标题}
演讲 | {中文标题}
```

选择最匹配的类型标签（专访/峰会/演讲/对谈/圆桌 等），然后接中文翻译后的标题。

## 4. 原文链接格式

放在 episode_content.md 最前面（紧接标题之后），同时包含播客节目名称和 YouTube 单集标题：

```
**{播客节目名称}**: {YouTube 视频标题}
{YouTube URL}（发布于 {发布时间}）
```

示例：
```
**Lenny's Podcast**: Why OpenAI is merging Codex and ChatGPT and the future of knowledge work | Andrew Ambrosino
https://www.youtube.com/watch?v=P3KDebPTUrw（发布于 2026 年 6 月）
```

> 注意：Show Notes 注入小宇宙时去掉 Markdown 加粗 `**`，写成 `原文链接：Lenny's Podcast - Why OpenAI is merging... {URL}` 即可。
