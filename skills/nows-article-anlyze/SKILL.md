## 概述

本技能对深度文章/报告进行标准化、可视化解析，**唯一核心交付物为专业美观、可离线运行的单文件 HTML**。

核心理念：通过金字塔逻辑重构与可点击流程图，将解析结果封装为交互式 HTML——流程图节点可跳转到内嵌原文段落，实现「逻辑结论 ↔ 原文依据」双向溯源。

## 文章类型与分层策略

**Step 0（必须首先执行）**：根据原文特征判定类型，激活对应分析层次。

| 内容特征 | 判定类型 | 分析层次 |
|---------|---------|---------|
| 多个产品/特性发布、Keynote/技术峰会实录 | **产品发布/Keynote** | L1 + L2 + L3（完整三层） |
| 行业趋势、市场规模、竞争格局、数据报告 | **行业研报** | L1 + 数据交叉校验 + 预测对比 |
| 管理方法论、组织理论、商业模式框架 | **商业理论** | L1 + 适用边界分析 + 反例测试 |
| 认知方法论、思维模型、观点论述 | **认知/观点** | L1 + 前提假设梳理 + 可证伪性讨论 |

**本 Skill 完整定义了「产品发布/Keynote」的全套路径，其余 3 类执行 L1 并各自追加表中注明的分析维度，不再单独展开。**

## L1 原文逻辑层（所有类型必做）

### Step 1 — 全文精读 & 全域抓取
通读全文，抓取以下要素（逐项检查，避免遗漏）：
- 顶层宗旨与核心观点
- 核心公式/定义/理论术语
- 分层模型与分类框架
- 正向结论 + 反向禁忌/限制条件
- 演化路径与落地规则
- **产品发布类额外**：列出所有独立产品/特性发布项

### Step 2 — 原文分段与锚点
将原文按逻辑单元切分为段落片段，为每段分配唯一锚点 ID（`src-01`、`src-02` …）。此步为后续流程图跳转建立溯源基础，片段将完整保留在 HTML「原文映射区」。

### Step 3 — 核心概念极简提纯
批量提取专业术语，统一格式输出：
> **概念名词**：一句话通俗释义（零门槛，外行秒懂）

### Step 4 — 核心观点金字塔重构
过滤背景铺垫与抒情赘述，保留纯因果推理链。提炼 **约 5 个核心观点**（按原文长度动态适配），结构为：
> 核心总观点 → 逐层递进推理 → 最终落地结论

所有关键转折、因果节点、核心判定语句**加粗高亮**。每个观点关联 Step 2 对应的原文锚点。

### Step 5 — 可视化流程图构建
用纯 HTML/CSS/SVG 绘制逻辑流程图，表达节点关系（递进 / 分支 / 聚合）。**每个节点绑定其依据所在的原文锚点 ID**，作为点击跳转目标。

### Step 6 — 全文逻辑闭环总结
纵向串联完整逻辑链，凝练最高立意。格式示例：
> 底层条件变化 → 个体能力变化 → 团队模式变化 → 组织体系变化 → 最终结果

## L2/L3 深度分析层（仅「产品发布/Keynote」类）

### Step 7 — 战略动因解码
对 Step 1 识别的**每个关键产品/特性发布**，逐个生成分析卡片，强制填充：

| 维度 | 核心问题 | 输出约束 |
|------|---------|---------|
| **时机动因** | 为什么是这个时间点？ | 从「技术成熟度 / 客户呼声 / 竞争压力 / 生态卡位」中选 1-N 项，附一句话依据 |
| **战略意图** | 在厂商版图中的角色？ | 从「防御性补课 / 进攻性领先 / 生态锁定 / 变现锚点」中选 1 项，附理由 |
| **信号意义** | 向市场传递什么？ | 从「技术路线选择 / 商业重心转移 / 合作生态变化」中选 1-N 项，附解读 |

每张卡片标注 `⚠️ 分析师判断` 以与原文内容区分。

### Step 8 — 竞争定位矩阵
基于 Step 7 的发布清单，结合模型内建行业知识，生成竞争定位矩阵：
- 筛选 **3-5 个**最值得对比的关键发布
- 与可确认的已知竞品逐项横向对比
- 每项标注定位：🏆 领先 / ⚖️ 持平 / 🏃 追赶，附简要判断依据
- 底部总结：「真正差异化发布」vs「行业标配补课」
- 若对某竞品信息不确定，标注 `⚠️ 知识截止至训练数据，可能存在遗漏`

### Step 9 — 行业趋势信号归纳
将整场 Keynote/峰会的发布视为整体信号集合：
- 提炼 **3-5 个反复出现的关键主题词**
- 判断共同指向的**行业演进方向**（1-2 句）
- 若模型存有该会议/厂商历史版本知识，对比 **6-12 个月间的变化与延续**；若无则注明 `⚠️ 无历史对比数据`
- 输出一句**可验证预测**：基于本次信号，预判 6-12 个月内可能发生的事件（标注 `🔮 预测`）

## Step 10 — HTML 交付规范

将以上全部分析结果封装为单文件 HTML，直接输出完整可保存源码。

### 视觉设计（语义级约束，AI 在约束内自由发挥）

- **风格**：商务质感、克制专业，避免廉价模板感
- **配色体系**：深蓝系主色 + 浅灰白背景 + 单一强调色用于高亮节点；L2/L3 深度分析区使用略有差异的背景色（如浅蓝紫调），与 L1「原文还原」层形成明确视觉区分
- **排版**：清晰字号层级，行高 1.6-1.8，中文无衬线系统字体栈，合理留白
- **卡片化**：各分区为独立卡片，圆角（~12px）、柔和阴影、适度内边距
- **细节**：分区标题配色块/图标强调，关键节点用高亮背景或加粗，概念库使用清晰条目分隔

### 流程图技术要求

- **纯原生实现**：HTML + CSS（flex/grid 布局节点）+ SVG 或 CSS 伪元素连线，**禁止使用 Mermaid 等任何外部库**
- **节点样式**：圆角矩形卡片，hover 时上浮/高亮/光标变手型，传达「可点击」
- **跳转交互**：节点为 `<a href="#src-XX">` 或绑定点击事件，平滑滚动到原文映射区对应段落，目标段落短暂高亮闪烁
- **结构支持**：递进（纵线）、分支（一对多）、聚合（多对一），连接线带箭头方向

```html
<!-- 流程图节点参考结构 -->
<a class="flow-node" href="#src-03" onclick="highlight('src-03')">
  <span class="node-title">核心结论</span>
  <span class="node-hint">查看原文依据 →</span>
</a>
```

### 原文映射区
完整保留原文逻辑段落，每段有独立 `id`（对应流程图节点）；被跳转命中时触发背景色短暂变化。

### 深度分析区（L2/L3）
**战略动因卡片**：每产品一张独立卡片，含产品名 + 时机动因（标签化）+ 战略意图（标签化）+ 信号意义（文本）。卡片顶部标注 `⚠️ 以下为分析师判断，非原文内容`。使用与 L1 有差异的背景色 + 左边框强调色条。

**竞争定位矩阵**：原生 `<table>` 渲染，表头深色底白字，内容行：特性 / 本次发布 / 竞品A / 竞品B … / 定位标签。矩阵下方附「竞争格局解读」段落。

**行业趋势信号**：
- 顶部：3-5 个主题词标签（横向排列，带色块）
- 中部：行业演进方向段落（加粗重点句）
- 若有历史对比：纯 CSS 小型时间线
- 底部：可验证预测框（虚线边框，浅黄背景，标注 `🔮 预测`）

### 交互与脚本（内联实现）
- `scroll-behavior: smooth` 或 `scrollIntoView` 平滑滚动
- 跳转高亮：临时 class，1-2 秒后自动移除
- **必做**：顶部分区导航锚点、返回顶部按钮
- **可选增强**：流程图节点同时高亮关联观点；L2/L3 分区默认展开但可折叠

### 工程约束
- **单文件**：所有 CSS/JS 内联，零外部依赖，浏览器双击打开即可
- **离线运行**：无任何网络请求
- **响应式**：桌面/移动端正常阅读，流程图窄屏纵向重排或横向滚动
- **输出形式**：直接输出完整 `.html` 源码，不截断、不输出预览片段

## 强制约束

1. 禁止冗余铺垫、场景描写、抒情语句——仅保留硬核推理与核心结论
2. 禁止使用 Mermaid 或任何外部图表库；流程图必须纯 HTML/CSS/SVG 实现
3. 流程图每个节点必须可跳转到 HTML 内原文对应段落
4. 禁止逻辑断层、层级混乱、缺失金字塔因果递进结构
5. 禁止遗漏原文核心模型、分层标准、禁忌规则、顶层宗旨
6. 最终交付必须为完整可保存运行的单文件 HTML 源码，禁止输出碎片化文本或预览格式
7. 产品发布/Keynote 类必须包含每个关键发布的动因解码 + 竞争定位 + 行业趋势，且与 L1 层有明确视觉区分
8. **长度自适应**：原文 < 1000 字时核心观点提炼为 2-3 个，流程图简化；原文 > 20000 字时原文映射区仅保留关键段落的切片，非全文复制

## 示例

**输入**（产品发布/Keynote 类）：
> [某厂商年度技术峰会 Keynote 全文实录，包含 A/B/C 三个新功能发布、产品路线图更新、生态合作宣布 …]

**输出**：
- 单文件 HTML，顶部为全文最高立意（一句话定性本次发布的战略信号）
- 概念库将通篇术语（如 Serverless、Multi-Agent、Zero-ETL）一一极简释义
- 金字塔逻辑揭示「厂商为什么要做这些事」的因果链
- 流程图展示 3 个发布的递进关系与依存
- 深度分析区：每个发布 1 张动因卡片 + 竞品对比矩阵 + 3-5 个行业主题词及 6 月预测
- 底部原文映射区锚点段落，点击流程图节点即可跳转溯源
