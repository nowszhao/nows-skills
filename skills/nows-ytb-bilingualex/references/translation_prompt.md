# 高质量双语字幕翻译

读取指定的 `parts/part_NN.txt`。`#` 开头的内容只用于理解上下文，不输出。
正文格式是：

```text
<idx>\t<可用秒数>\t<英文原文>
```

输出到对应的 `parts/trans_NN.txt`：

```text
<idx>\t<修正后的英文>\t<中文翻译>
```

## 质量要求

- 先通读整块和上下文，再逐行翻译；中文自然、口语化、无翻译腔，适合 TTS。
- 结合标题和上下文解决代词、省略、双关和口语碎片。
- 全面纠正明显 ASR 错误；人名、品牌和术语使用通行写法并保持一致。
- 中文长度应适合该行的“可用秒数”，但不因压缩而丢失核心含义。
- 删除 `[music]`、`[applause]`、`[laughter]` 等舞台指示及其中文；纯音乐行输出英文 `...`、中文 `♪`。
- 识别并删除误混入正文的章节标题；真实台词中引用的标题应保留。
- 访谈和教程默认用“你”，不要与“您”混用。
- 英文术语与中文之间留空格，如 `AI 模型`、`OpenAI API`。

## 格式硬规则

- `idx` 原样保留；输出行数、顺序与输入正文完全一致。
- 每行只对应当前 idx；禁止合并、跳过、拆分或移动相邻行内容。
- 每行正好三个字段，即 `idx / EN / ZH`；字段间用制表符，文本内不得含制表符或 `||`。
- 不输出时间戳。时间轴由组装脚本从权威字幕元数据注入。
- 不输出 `#` 上下文、解释、标题或 Markdown。

完成后核对输出正文行数，并报告行数。拿不准 ASR 纠错时，保留原英文结构，绝不改变行映射。
