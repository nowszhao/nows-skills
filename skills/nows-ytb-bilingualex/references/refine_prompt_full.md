# FULL 语义断句：只输出边界

读取指定的 `refine_parts/refine_part_NN.txt`，判断自然、完整的英语句子边界。
输入中的词已经由脚本标为 `W000001:word`；模型只决定句末位置，不复制或改写原文。
每个 `Lxxxxx start-end` 是原字幕行及时间范围，可用来判断停顿和原始边界，但不能输出。

## 输出

每个句末一行：

```text
W000012\t.
W000026\t?
W000041\t!
```

硬规则：

- 只输出 `W<编号>\t<标点>`；标点只能是 `.`、`?`、`!`。
- 只提交文件头 `Commit range` 内的句末。范围外的词只是只读上下文。
- 编号严格递增，不重复。
- 当前文件的 `Commit range` 若包含整部视频最后一个词，必须输出该词为句末。
- 通常每句 5–16 词；专名、固定短语和完整从句不要拆散。
- 不让句子悬空在 `and`、`because`、`which` 等连接结构上。
- 可跨原字幕行判断边界。不要输出时间戳、英文原句、解释或 Markdown。

脚本会从原始词流重建文本，因此不会发生删词、改词或词序漂移。
