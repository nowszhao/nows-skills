# Lakehouse 数据平台 v2.4（私有化部署版）

## 定位

面向企业数据团队的一站式数据资产管理与分析平台，提供数据源接入、数据集管理、任务调度、查询分析等能力。私有化部署，运行在客户内网。

## 部署形态

- 形态：**私有化**（客户机房 / 客户云内网 / 国产化信创环境）
- 典型部署环境：Kubernetes 集群（3 节点起步）
- 离线约束：**完全离线**，不依赖任何公网服务；所有镜像通过离线安装包交付
- 国产化适配：信创操作系统、信创数据库、信创芯片可选

## 核心域

- **数据管理** (`data-management`)：数据源 / 数据集 / 元数据
- **任务管理** (`task-management`)：调度任务 / 执行历史 / 任务编排
- **查询分析** (`query-analytics`)：SQL 查询器 / 结果可视化
- **平台管理** (`platform-admin`)：租户 / 用户 / 权限 / 配额 / 审计

## 用户角色

详见 `_meta/roles.md`。简要：

- **Owner**：租户管理员，全部权限
- **Admin**：模块管理员，限定模块的管理权限
- **Developer**：可创建编辑数据集 / 任务 / 查询
- **Viewer**：仅查看

## 多租户模型

- 所有业务对象（数据集 / 任务 / 查询）均**租户隔离**
- 平台管理员可跨租户管理，业务用户仅在所属租户内可见
