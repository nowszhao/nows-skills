联动说明（无 UI 变化）

端到端流程

点击节点可跳转到对应页面（如已配置 data-page）

flowchart LR
  A[用户进入 数据集列表] --> B{选中要导出的项}
  B -->|至少 1 项| C[点击 批量导出]
  C --> D[弹出 批量导出页]
  D --> E[选择字段范围]
  E --> F[提交导出任务]
  F --> G[任务进入 任务列表]
  G --> H{完成?}
  H -->|成功| I[下载文件链接]
  H -->|失败| J[错误提示+重试]
