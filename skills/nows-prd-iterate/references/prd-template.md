# 迭代型 PRD 模板（私有化 ToB 强化版）

> **边界**：PRD 只写 What & Why（业务规则 / 字段约束 / 状态机 / 权限 / 影响面 / 升级兼容）。
> 不写 How（API、DDL、技术选型、Feature Flag、P99/QPS）—— 这些归 Tech Spec。
>
> **私有化 ToB 特化**：必谈租户隔离 / 升级兼容 / 离线约束 / 部署配置 / 审计合规；
> 不谈灰度百分比 / A/B / DAU/MAU。
>
> 所有变更必须标 `[page_id = X] [区域 = Y]` 锚点。
> 标 `（如适用）` 的节没内容直接删。

## 10. 私有化部署专项（必填，不适用则写"无影响"并说明）

### 10.1 多租户影响
- 是租户隔离的还是全局变化？

### 10.2 升级与兼容
- **老客户升级路径**：从 vN 升到 vN+1 是否需要停机 / 数据迁移 / 配置调整？
- **老数据兼容**：已有 Dataset 升级后是否会被影响？是否需要 backfill？
- **接口兼容**（如对接客户自己系统）：是否破坏现有契约？是否需要保留兼容层一段时间？
- **回滚方案**：升级失败如何回滚？数据是否可回退？

### 10.3 部署 / 配置影响

- 新增依赖服务 / 容器：…
- 资源占用变化：…
- 安装包变化：…

### 10.4 离线 / 内网约束
- 本特性是否依赖公网服务（如外部 SaaS / CDN）？
- 离线环境下如何降级？
- 是否需要私有镜像 / 离线资源包？

### 10.5 审计与合规
- 哪些操作需写审计日志？字段：操作人 / 时间 / 对象 / 动作 / 结果
- 是否涉及敏感数据（PII / 业务机密）？是否需脱敏 / 加密？
- 是否触发客户合规要求（如等保、行业认证）？
